LANDING EDAI TECH - proyecto Next.js completo

Estructura (todo va en la RAÍZ del repositorio, no dentro de otra carpeta):

  package.json        dependencias y comandos (Vercel lo necesita para compilar)
  next.config.mjs     configuración de Next.js
  tsconfig.json       configuración de TypeScript (alias @/)
  next-env.d.ts       tipos de Next.js
  .gitignore          archivos que no se suben
  app/layout.tsx      estructura base de la página (html, idioma, colores)
  app/page.tsx        página de inicio
  components/LandingEdai.tsx   la landing completa
  public/casos/*.jpg  fotos de los casos

En Vercel: Settings > Build and Deployment > Framework Preset = Next.js
(Root Directory vacío). Luego "Redeploy".

Probar en tu PC:  npm install   y luego   npm run dev   (abre http://localhost:3000)
